## 2026.10.7 (2026-10-12)

### [A11y]

- If you add a Button, Link, Tag, Modal opener, Menu button, Tooltip, Notification or Statistic and leave it without text, your site doesn't show it.
- If you leave a form field's label or a Modal's heading empty, your site shows a default one, such as "Label" or "Modal heading".

### [Improvement]

- You can add a Tag to a Hero.
- New blocks start empty and show a hint.
- Ability to quickly add the same type of blocks by pressing Enter: Tag, Button, Link and Modal opener.
- Enter no longer adds a second line to block labels and headings.
- A new Checkbox, Toggle or Menu button puts the cursor in its label.
- Typing in a Select or Dropdown's options stays where the cursor is.
