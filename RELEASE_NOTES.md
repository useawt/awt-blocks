## 2026.10.9 (2026-10-14)

### [A11y]

- In Toggle block, screen readers no longer read the On/Off text as part of its name.
- In Menu button block, screen readers announce each item as a menu item with its position.
- In the header navigation, screen readers announce a submenu as a button that shows its links, not as a menu.
- In Tag block, a label too long for the tag shows its full text on hover, and in a tooltip that opens from the keyboard or by touch.
- If you set an accessible name in a block's Accessibility panel, screen readers now announce it on the block's field, button or code area.

### [Improvement]

- On sites with WordPress debugging on, a new Hero no longer shows its heading and description twice.
